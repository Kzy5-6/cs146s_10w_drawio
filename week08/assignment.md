# 第 8 周：从需求构建端到端应用

## 目标

基于 [`course_project`](../course_project/README.md) 的 API，从需求到可运行原型完成端到端开发，覆盖表单、服务接口、数据流和基本错误状态。

## 作业任务

1. 从 `course_project/frontend` 的静态页面起步，为纪要管理写目标用户、核心任务、范围和验收条件。
2. 补齐 `app.js` 中的 TODO，连接列表和创建接口，使用安全 DOM API 渲染用户文本。
3. 至少覆盖加载、成功、空列表和失败状态；对输入做必要校验并避免重复提交。
4. 使用 AI 开发工具迭代界面，说明所选技术栈及模型/API 依赖。
5. 按验收条件手动走查并保留截图或短录屏；记录人工调整和未完成项。

用本机静态服务器提供前端页面；如浏览器因跨域策略拦截 API 请求，为开发来源配置最小范围的 CORS，并说明该配置适用的环境。

## 提交内容

- 需求和界面草图；
- 可运行源代码及启动说明；
- `report.md`：验收走查、变更记录和已知限制。
