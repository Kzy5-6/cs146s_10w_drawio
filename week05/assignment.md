# 第 5 周：用终端工作流重复开发任务

## 目标

把 [`course_project`](../course_project/README.md) 的纪要导出任务变成可重复运行的 CLI 命令，并让 Agent 在明确的命令边界内协助完成。

## 作业任务

1. 从 `cli_starter.py` 开始实现导出工具：请求 `GET /notes` 并把响应写为 JSON 文件。
2. 保留 `--base-url`、`--output` 和 `--dry-run` 参数；处理 HTTP 错误、无效 JSON 和文件写入失败。
3. 确保 dry-run 不创建、不覆盖目标文件，并在帮助信息中写清楚默认行为。
4. 在项目说明中记录依赖安装、命令用法和示例；让 Agent 执行一次导出，先审查目标路径。
5. 验证正常输入、错误输入、目标文件已存在和 dry-run 场景，并说明命令能否安全重复运行。

## 提交内容

- CLI 脚本或配置；
- 使用说明；
- `report.md`：测试场景、执行记录、失败处理及安全边界。
