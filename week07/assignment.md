# 第 7 周：进行有证据的 Agentic Code Review

## 目标

对 [`course_project`](../course_project/README.md) 中一项课程变更进行 Agentic Code Review，比较审查意见与代码事实，筛选可复现的问题，并把修复和验证连接到具体 diff。

## 作业任务

1. 使用第 3 或第 4 周的纪要详情/删除变更，准备一个 PR 或等价 diff，附上需求和验收标准。
2. 让代码审查工具检查该变更，要求每条意见指出文件位置、风险和复现依据。
3. 逐条核验意见，标注为已确认、误报、重复或证据不足，并说明判断理由。
4. 修复确认的问题，补充相应测试或检查，再请审查工具复查。
5. 报告至少一个审查工具未发现的问题，或解释本次审查为何没有观察到遗漏。

## 提交内容

- 原始变更和修复后的 diff；
- 审查意见及逐条判定；
- `report.md`：复现、验证、误报和剩余风险。
