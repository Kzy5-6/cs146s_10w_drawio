# 第 10 周：课程项目与 Software Factory 复盘

## 目标

把需求、规划、实现、审查、测试和运行反馈连成一条可追溯的软件交付流程，并总结 AI 在其中适合承担的工作。

## 作业任务

1. 以 `course_project` 为底稿，或选择一个自己持续演进的小型代码库，定义用户问题、非目标和成功指标。
2. 展示从规格到实现、验证、审查和运行观察的完整工作流；标出人工决策与 Agent 自动化边界。
3. 提供可复现的启动和验证步骤，说明依赖、环境变量和数据要求。
4. 记录至少一次 Agent 失败或偏差，以及你如何检测、修复并防止问题再次发生。
5. 复盘本学期工作流：哪些任务适合委派，哪些需要人工主导，下一轮最值得改进的一个环节是什么。

## 提交内容

- 可演示项目及源代码；
- 项目说明、规格、测试与运行文档；
- `report.md`：演示流程、证据索引、Agent 边界和课程复盘。
