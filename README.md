# CS146S 课程实践

这是一份面向本课程学生的独立教学仓库，用于组织五周课程的课件、实验和作业。课程保留八次编程作业，不设期末项目。课程主题以公开课程资料为参考，并按本班学生的环境与教学安排调整。

## 从这里开始

1. 按 [五周压缩学习计划](./five_week_plan.md) 学习，查看每周目标、课件、英文 Lecture 和作业对应关系。
2. 按作业文件完成 HW1–HW8；作业内容与提交要求以各文件为准。
3. HW3–HW8 使用共享的 [课程贯穿项目](./course_project/README.md) 作为起始代码。
4. 第 5 周以 HW8 完成和统一验收收尾，不增加其他项目。

## 课程课件

Fall 2025 讲座课件已按周整理在 [课件目录](./slides/README.md)，可从课程安排直接打开。

## 本地模型课程基线

前两周统一使用 Ollama 在本机运行 `qwen3:4b`。先按周一作业完成安装和连通性检查，再用同一模型开展提示实验，记录模型标签、运行环境、提示词、耗时和观察结果。模型文件由学生本机下载；仓库不附模型权重、答案或已完成作业。

```powershell
ollama pull qwen3:4b
ollama run qwen3:4b
```

具体安装说明见 [第 1 周作业](./week01/assignment.md)。

## 仓库约定

- 这里面向学生，只放课程说明、未完成的起始材料和公共阅读资源。
- 作业提交、个人解答、评分材料和教师参考答案不放入本仓库。
- 不要把个人 API 密钥、`.env`、模型权重、运行日志或生成结果提交到 Git。
- 每学期开始前由授课教师复核模型版本、安装步骤、软件版本和外部资源可用性。
