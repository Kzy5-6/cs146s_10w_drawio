# 第 6 周：测试与安全审查 AI 生成代码

## 目标

用独立检查验证 `course_project` 的行为，并从输入验证、错误处理、日志和依赖角度审查应用。起始代码使用内存存储，不可放入真实纪要。

## 作业任务

1. 以起始项目为基线，为创建、列表和第 3 周加入的详情查询列出至少五条验收条件，包含空白标题、过长文本和未知 ID。本周为删除操作补充 `DELETE /notes/{note_id}`，并定义成功删除与未知 ID 的响应。
2. 为这些条件编写自动化测试，并区分单元测试与 HTTP 集成测试。
3. 检查输入校验、异常响应、日志中可能出现的纪要内容和依赖版本；记录风险、影响和修复优先级。
4. 设计一个包含 HTML/脚本片段的标题或正文，检查前端是否会把用户文本当成可执行标记。
5. 让 Agent 提议修复，审阅 diff 并重跑相关检查；报告修改前后的证据。

## 提交内容

- 自动化测试；
- 安全检查清单和修复 diff；
- `report.md`：验收条件、运行结果、风险判断和仍未覆盖的边界。
