# 第 3 周：把项目上下文交给 AI IDE

## 目标

使用仓库中的 [`course_project`](../course_project/README.md) 作为起始代码。练习把需求、项目结构和运行约束整理成 Agent 可检查的上下文，让工具先理解代码，再实施范围明确的修改。

## 作业任务

1. 阅读起始项目的 README、API 入口和数据模型，画出简短的请求处理路径。
2. 写一份面向 Agent 的项目说明：用途、目录、运行/验证命令、内存存储限制和不可触碰的行为。
3. 为“按 ID 查询单条纪要”功能写需求和验收条件，包括不存在的 ID。
4. 使用 AI IDE 完成功能并补充验证。保留关键提示、Agent 计划、实际 diff 和命令结果。
5. 对比修改前后，说明项目上下文中哪些信息减少了误解，哪些信息仍缺失。

## 提交内容

- 项目上下文文件和功能需求；
- 代码变更 diff；
- `report.md`：记录使用的工具、提示、验证命令及结果、人工修改和反思。

不得使用含密钥、私人数据或未经授权的代码库。
