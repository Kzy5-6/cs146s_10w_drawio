# 第 4 周：设计可监督的 Agent 工作流

## 目标

基于 [`course_project`](../course_project/README.md)，把一项多步骤开发任务拆成可观察、可中止、可复核的阶段，练习在人类规划、Agent 实施、自动验证和人工复核之间安排检查点。

## 作业任务

1. 选择为起始 API 添加“删除指定纪要”功能，写出任务边界、预期状态码和成功条件。
2. 设计一个至少含计划、实施、验证、复核的工作流，标明各阶段输入、输出和人工确认点。
3. 要求 Agent 在修改前检查路由、数据存储和测试，不允许清空或重建项目文件。
4. 运行工作流并保存计划、变更 diff、验证记录和人工介入说明。
5. 指出一个可能导致 Agent 错删数据或错误报告成功的情形，并说明流程怎样限制它。

## 提交内容

- 工作流说明或配置；
- 完成的代码改动；
- `report.md`：阶段记录、检查点、偏差与改进建议。
